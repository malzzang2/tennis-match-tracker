🎾 테니스 게임로그 사용 설명서

테니스 복식 경기를 기록하고, NTRP 기반으로 전력을 분석해주는 웹앱입니다. 설치·로그인 없이 브라우저에서 바로 쓰고, 데이터는 내 기기에만 저장됩니다. 처음이라면 아래 순서대로 따라와 보세요.

0. 시작하기 — 사용자명 입력

앱을 처음 열면 "테니스 게임로그를 시작해볼까요?" 창이 뜹니다. 사용자명(내 이름 또는 닉네임)을 입력하고 시작하기를 누르면 시작됩니다.

이 이름은 대시보드 제목("○○의 게임로그")과 경기 입력 화면의 "나"에 표시됩니다.

나중에 바꾸고 싶으면 대시보드 맨 아래 → 사용자명 수정에서 변경할 수 있어요.

1. 화면 구성 한눈에 보기

상단에 탭 3개가 있습니다. 이 3개만 이해하면 됩니다.

  • 대시보드 — 요약 성적 + NTRP 분석 + 최근 경기 + 데이터 백업/설정
  • 경기 기록 — 경기 입력, 경기 목록, 상대방(NTRP) 관리
  • 통계 — 전체·NTRP·월별·파트너·상대·구장별 상세 통계

2. 내 NTRP 설정하기 (분석 기능의 기준)

전력 분석을 쓰려면 먼저 내 NTRP를 정해두는 게 좋습니다.

2내 NTRP에서 값을 선택(예: 3.0)하고 저장

3저장하면 옆에 "현재 내 NTRP 3.0"이 표시됩니다. 모르면 "모름"으로 둬도 됩니다.

3. 상대방(파트너) NTRP 등록하기

파트너와 상대 선수의 NTRP를 등록해두면, 경기를 기록할 때 자동으로 불러와 전력차를 계산해줍니다.

1경기 기록 탭으로 이동

2아래쪽 상대방 관리 섹션에서

3상대방 이름과 NTRP를 입력하고 추가

  • 이름은 파트너·상대 구분 없이 한 곳에서 관리됩니다. 같은 사람이면 같은 NTRP가 적용돼요.
  • 이름은 대소문자를 구분하지 않습니다. "John"으로 등록했으면 "john"이라고 적어도 잘 불러옵니다.
  • 이미 등록된 이름을 또 추가하면 "이미 등록된 상대방입니다. (NTRP 3.5)"처럼 기존 값을 알려줍니다.
  • 목록은 10명씩 나눠 보이고, 이전 / 다음 버튼으로 넘겨봅니다.
  • 수정 / 삭제로 언제든 값을 바꿀 수 있어요. (상대 정보를 지워도 이미 기록한 경기는 유지됩니다.)

4. 경기 기록하기 (핵심 기능)

경기 기록 탭 위쪽 입력 폼에서 경기를 기록합니다.

  • 경기 날짜 — 기본값은 오늘 (필수)
  • 경기 형태 — 복식 고정
  • 구장 — 선택 입력 (한번 입력하면 다음부터 자동완성)
  • 나 / 내 파트너 / 상대 선수 1·2 — 이름 입력. 등록된 NTRP가 있으면 이름 옆에 자동 표시
  • 경기 점수 — 내 점수 / 상대 점수를 숫자로 입력 (필수)
  • 경기 시간 / 메모 — 선택 입력
점수를 넣으면 승·무·패가 자동으로 판정됩니다. 내 점수가 크면 승, 같으면 무, 작으면 패이고, 입력하는 즉시 "결과: 승리" 같은 미리보기가 뜹니다.

상대 선수 2는 비워도 됩니다. 이름 옆에 "NTRP 3.5"(등록됨) 또는 "NTRP 미등록"이 표시돼, 누구 NTRP가 빠졌는지 바로 알 수 있어요.

5. 경기 목록 보기 · 수정 · 삭제

입력 폼 아래 경기 목록에 최근 경기부터 카드로 쌓입니다.

  • 각 카드: 날짜, 승/무/패 배지, 상대, 점수(내:상대), NTRP 전력 분석(우리팀/상대팀 평균, 전력차, "상대 전력 우세" 등)
  • 5경기씩 나눠 보이고 이전 / 다음 버튼으로 넘깁니다.
  • 수정: 카드의 수정 버튼 → 폼에 값이 채워지고, 고친 뒤 저장
  • 삭제: 카드의 삭제 버튼 → 확인 후 삭제

NTRP가 등록 안 된 사람이 있으면 그 경기 카드엔 "NTRP 미등록"으로 표시됩니다. 성적 기록엔 영향 없어요.

6. 대시보드 — 내 성적 한눈에

대시보드 탭 위쪽에 핵심 숫자가 모여 있습니다.

  • 전체 요약: 총 경기 / 승·무·패 / 승률 / 연승·연패 / 최근 10경기 / 요즘 폼
  • NTRP 경기 분석: 평균 우리팀 NTRP, 평균 상대팀 NTRP, 평균 전력차
  • NTRP 전력별 승률: 우세 / 동급 / 열세 구간별 경기 수·승률
  • 전력 열세 경기 분석: 열세 경기 수·승률·승리 수, "가장 큰 전력 열세 승리"
  • 최근 경기: 최근 5경기 요약
승률은 승 ÷ (승 + 패)로 계산하고, 무승부는 승률에서 제외합니다. 무승부는 경기 수엔 포함돼요.
요즘 폼은 최근 10경기 승률을 전체 승률과 비교해 알려주는 재미 요소예요. 최근이 더 좋으면 "요즘 잘나감 🔥", 비슷하면 "그럭저럭 침 😐", 나쁘면 "최근 부진함 😮‍💨"으로 표시됩니다. (경기 표본이 적으면 "아직 표본이 적어요"로 나와요.)

7. 통계 탭 — 자세히 파고들기

통계 탭에서는 더 상세한 표를 볼 수 있습니다.

  • 전체 / NTRP 전력별 / 전력 열세 분석
  • 월별: 월별 성적 + NTRP 평균·전력차·열세 경기
  • 파트너별: 파트너별 성적 + 평균 우리팀/상대팀 NTRP·전력차·열세 승률
  • 상대별: 상대별 성적 + 등록 NTRP·평균 전력차
  • 구장별 통계

표가 넓으면 좌우로 스크롤해서 NTRP 항목까지 볼 수 있어요.

8. 데이터 백업 · 복원 (꼭 해두세요)

데이터는 내 기기(브라우저 localStorage)에만 저장됩니다. 브라우저 캐시를 지우거나 기기를 바꾸면 사라질 수 있으니 주기적으로 백업하세요.

  • 대시보드 → 데이터 관리
  • 데이터 백업: JSON 파일로 내려받기 (경기·상대 NTRP·내 NTRP·사용자명 모두 포함)
  • 데이터 복원: 백업 파일을 불러와 되돌리기

PC에서 기록하고 백업 파일을 폰으로 옮겨 복원하면, 기기 간 이전도 됩니다.

9. 자주 묻는 것들 (FAQ)

Q. 회원가입이나 로그인이 필요한가요?
아니요. 사용자명만 정하면 되고, 데이터는 내 기기에만 저장됩니다.

Q. NTRP를 모르면 못 쓰나요?
성적 기록·통계는 NTRP 없이도 다 됩니다. 전력 분석만 등록된 경기에서 표시돼요.

Q. 무승부도 기록되나요?
네. 점수를 같게 입력하면 자동으로 무승부로 판정됩니다.

Q. 이름 대소문자를 다르게 적었어요.
NTRP 조회는 대소문자를 구분하지 않아 그대로 잘 불러옵니다.

Q. 데이터가 사라질까 걱정돼요.
정기적으로 데이터 백업을 눌러 파일로 보관하세요.
